# Robofriends React Application

A responsive React application that fetches user card profiles from a public API and allows users to search and filter them dynamically in real-time.

## Tech Stack
* React.js (functional components, state management)
* JavaScript (ES6+, Fetch API)
* CSS (Tachyons library, Custom styles)

## How to Run
Navigate into the project directory, install the required node packages, and start the local development server.

```bash
npm install
npm start
```
The application will open automatically on http://localhost:3000.
